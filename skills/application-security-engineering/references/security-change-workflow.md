# Security change workflow

1. Define assets, actors and trust boundaries.
2. Identify hostile input and data egress.
3. Find existing security owners.
4. Select controls using defence in depth.
5. Preserve ordinary UX where risk permits.
6. Add negative and abuse tests.
7. Verify logs and errors do not leak sensitive data.
8. Verify provider settings or create exact external actions.
9. Update threat model, findings, ADRs and ARRs.
10. Run security, quality and hygiene checks.

Use OWASP ASVS or another applicable standard as a verification catalogue, not as a substitute for threat modelling.

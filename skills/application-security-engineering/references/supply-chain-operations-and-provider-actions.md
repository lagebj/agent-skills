# Supply chain, operations and provider actions

## Supply chain

Use dependency alerts, security updates, code scanning, secret scanning, push protection, lockfiles, least-privilege workflows and reviewed actions. Do not expose production secrets to untrusted pull requests.

## Logging and incidents

Log authentication, authorisation, privilege and destructive events with correlation metadata. Exclude secrets and sensitive payloads. Maintain incident, revocation and recovery procedures.

## Recovery

Test restore, export, deletion and suspension. Security includes integrity and availability.

## Provider actions

A provider setting is part of the architecture. Automate only with safe existing credentials. Otherwise record exact navigation, desired value, reason, evidence and rollback. Never claim completion without verification.

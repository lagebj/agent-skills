# Security change checklist

- [ ] Actors and trust boundaries identified
- [ ] Authentication and authorisation separated
- [ ] Resource and tenant ownership verified
- [ ] Server input validated and bounded
- [ ] Output and logs minimised
- [ ] SQL and database privileges reviewed
- [ ] External requests allowlisted
- [ ] Secrets and environment scopes reviewed
- [ ] Negative and abuse tests added
- [ ] Dependencies and workflows reviewed
- [ ] Provider actions verified or documented
- [ ] Threat model, ADRs, ARRs and findings updated
- [ ] Ordinary UX not degraded without justification
